# PathHydra system conformance

This ledger maps every normative section and every originally open decision in
[`PATHHYDRA_SYSTEM_SHAPE.md`](../PATHHYDRA_SYSTEM_SHAPE.md) to the one current
pre-release implementation. A status has exactly one of three meanings:
`implemented` is executable behavior, `selected policy` is an evidence-backed
choice among valid implementations, and `explicitly outside system scope` is a
boundary stated by the system shape itself.

Evidence tokens use `repository/path#exact symbol`. Run the local stale check
after code, test, decision, or reference renames:

```powershell
powershell -NoProfile -File Scripts/check-system-conformance.ps1
```

The reviewed inventory currently contains 141 `SS-*` requirements. The check
rejects duplicate, malformed, nonterminal, or removed rows in addition to stale
paths and symbols; adding a newly identified normative row remains allowed.
