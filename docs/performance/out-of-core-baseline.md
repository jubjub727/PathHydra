# Out-of-core baseline

No CUDA or CPU speedup claim is made from the implementation fixtures. Ordinary tests force 48-byte one-relation topology partitions and a one-entry host cache to prove deterministic segmentation, eviction, path evidence, and resident/partitioned response agreement.

Release measurements must report graph counts, partition and bundle bytes, cache sizes, storage type, toolchain, hardware, cold/warm state, and correctness against an untimed CPU response. The opt-in greater-than-10-GiB workload is manual because it consumes substantial disk and time. DirectStorage remains evidence-gated; conventional checked reads are the correctness baseline.
